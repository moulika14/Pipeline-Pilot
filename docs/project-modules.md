
# PipelinePilot – Project Modules

## 1. CI/CD Pipeline Module
Automatically triggers the build and testing process when code changes are pushed to GitHub.

## 2. Docker Containerization Module
Packages the application and its dependencies into Docker containers for consistent execution.

## 3. Cloud Deployment Module
Handles application deployment to AWS EC2 cloud infrastructure.

## 4. Infrastructure as Code Module
Uses Terraform to provision and manage cloud infrastructure.

## 5. Application Monitoring Module
Uses Prometheus to collect application metrics and Grafana to visualize monitoring information.

## 6. Failure Handling Module
Detects deployment failures, provides notifications and supports rollback to a previous stable version.

## 7. Deployment Dashboard Module
Displays build status, test results, deployment history and application health information.
